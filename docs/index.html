Download Hearth TV
First install
  1. Tap Download Hearth TV. Chrome downloads hearth-tv.apk.
  2. Open the download. If Chrome asks to allow installing unknown apps, allow it once.
  3. If Play Protect warns about an unknown developer, choose Install anyway.
  4. Open Hearth TV on the home Wi-Fi and follow the setup screen.
Updates

The app tells you when a newer version exists and brings you back here. Installing over the top keeps your pairing and settings.

Built for the Family Room. Runs entirely on your home network; nothing leaves the house.
